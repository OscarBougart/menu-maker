## Priority Issues

**[P1] `status-error` color fails WCAG AA contrast** — `--blood-bright: #7a4040` against `--panel: #111315` ≈ 2.7:1. The error state is the most safety-critical color signal in the UI and it's the one that fails. Fix: lighten status-error to ≈ #c46060 (≥4.5:1 against panel). One token change.

```css
/* current */
.status.status-error { color: var(--blood-bright); }

/* fix */
.status.status-error { color: #c46060; }
```

**[P1] Space key on `menu-card` causes page scroll** — `onKeyDown` handles `Enter` and `Space` but is missing `e.preventDefault()` on Space. Page scrolls before the load fires. Fix:

```jsx
onKeyDown={(e) => {
  if (e.key === 'Enter' || e.key === ' ') {
    e.preventDefault();
    loadMenu(m.key);
  }
}}
```

**[P2] `.extract-progress` has no `aria-live`** — extraction is a 10–30s operation announced visually via dots + label, but the extraction block has no live region. Screen readers never hear that extraction started or finished. Fix: add `aria-live="polite" aria-label="Extracting design rules"` to the `.extract-progress` container.

**[P2] `transition: all` on 7 element classes** — `.btn`, `.dropzone`, `.preset-chip`, `.menu-card`, `.menu-card-del`, `.source-chip`, `.status-dot` all use `transition: all`. This transitions layout properties (width, height, padding) on hover, which triggers expensive paint + composite. Enumerate only the properties that actually animate: `color, background, border-color, opacity, box-shadow`.

**[P2] `:root` `--line` and `--line-bright` use legacy `rgba()`** — both tokens use `rgba(154, 149, 140, 0.14)` and `rgba(196, 160, 90, 0.3)`. All other color-mix usage in the file uses modern `color-mix(in srgb, ...)`. Inconsistency in the token layer. Fix:

```css
--line: color-mix(in srgb, var(--bone-dim) 14%, transparent);
--line-bright: color-mix(in srgb, var(--brass-bright) 30%, transparent);
```

**[P3] `box-shadow: 0 50px 140px rgba(0,0,0,0.8)` hard-codes black** — should use a tinted shadow derived from the near-black token. Minor, but inconsistent with the token system.

**[P3] `print-hint-dismiss` aria-label reads "Dismiss"** — lacks context. Change to `"Dismiss print hint"` so screen reader users navigating by landmark know what they're dismissing.
