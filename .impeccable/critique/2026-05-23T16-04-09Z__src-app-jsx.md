## Anti-Patterns Verdict

Does not read as AI-generated. Specific palette, authored typographic pairing, real product concept (House Brain). One soft second-order tell: dark tool + gold accent + serif data display is a recognizable lane for the domain. P3 concern only.

Deterministic scan: bundled detect.mjs not found; fell back to manual code review.

## Overall Impression

Focused, well-structured tool with genuine character. Biggest gap is not visual — it is the silence between actions. Users receive no explanation of why decisions matter, what just happened, or how to fix it when things go wrong.

## What's Working

1. Sequential workflow is genuinely clear. Step 1 → Step 2 maps directly to UI structure.
2. Saved menus grid with per-palette card tinting — users can find menus by palette without reading names. Genuinely clever.
3. Button hierarchy: one solid brass CTA, brass outline secondaries, desaturated wine for merge.

## Priority Issues

**[P1] Two-tier memory system invisible at decision point** — "Save as Template" and "+ Add to House Brain" appear side-by-side with no explanation. Users corrupt the House Brain on session one by merging without understanding. Fix: one-line description under each button. Suggested: /impeccable clarify

**[P1] Errors surface in wrong place at wrong size** — async errors land in 8px corner badge with raw err.message strings. Primary failure (bad API key) is effectively silent. Fix: inline error display within the section that triggered the failure. Suggested: /impeccable harden

**[P2] Add to House Brain is irreversible with no warning** — merge permanently alters _master.json with no confirmation and no undo. Fix: inline confirm state on first click (no modal). Suggested: /impeccable harden

**[P2] Export always fails silently for dark menus** — window.print() with no instruction. Dark backgrounds require "Background graphics" in print dialog; nearly every first export produces a white PDF. Fix: one-time dismissible callout above export buttons. Suggested: /impeccable harden

**[P2] No progress signal for 10-30s operations** — Add to House Brain shows no loading state in the sidebar block. Fix: inline animated indicator within block while busy. Suggested: /impeccable harden

## Persona Red Flags

**Jordan (First-Timer):** Picks wrong save mechanism (House Brain) without understanding. Loses the entire payoff on export — dark menu produces white PDF. Critical failure point.

**Alex (Power User):** Inline edits silently overwritten when re-composing. No bulk delete. No side-by-side comparison.

**The Bar Owner (Project-specific):** Palette swatches show hex values, meaningless to non-designers. No affordance that menu text is editable before clicking it. No loading signal in Step 1 section during extraction.

## Minor Observations

- Command key symbol ⌘ on House Brain header is Mac-specific, confuses Windows users.
- ☷ (Trigram for Earth) on Saved Menus likely renders as box on Windows.
- Swatch title attributes show hex values; role names (Accent, Background, Text) would be more useful.
- Column toggle (1/2/3) has no visible label for sighted users.
- Booklet canvas overflow has no scroll affordance.

## Questions to Consider

- What if "Save as Template" and "+ Add to House Brain" were a single "Save" button with a two-option explainer on first use?
- Does export need a one-time "print settings" callout, or should the UI detect dark backgrounds and warn proactively?
- What if palette swatches showed role names on hover instead of hex values?
