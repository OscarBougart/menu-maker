## Priority Issues

**[P1] House Brain merge has no panel-level progress signal**
Merge triggers a 10-30s AI call with no panel indicator. Extraction got inline progress this session; merge did not. Status badge updates but nothing in the panel block signals activity.
Fix: Add `merging` state with `.extract-progress` dots below the confirm buttons.

**[P2] Regenerating with existing menu shows no canvas loading state**
When menu exists and user clicks Compose Menu again, canvas shows the old menu unchanged. Only feedback is the 8px status badge spinner.
Fix: Set `menu` to null at the start of generate(), restore on success, keep previous on error.

**[P2] Cmd+Enter keyboard shortcut is invisible**
Implemented but undiscoverable. No hint that it exists.
Fix: Add kbd hint at 9px alongside the brief textarea label: "Cmd+Enter to compose."

**[P3] loadMenu has no loading indicator**
Clicking a saved menu card gives zero feedback until JSON arrives.
Fix: Set setBusy(true) in loadMenu.

**[P3] Error banner not visible when panel scrolled down**
Banner appears at top of panel; if user is scrolled to Step 2 or Saved Menus, they may miss it.
Fix: position: sticky; top: 0; z-index: 10 on .error-banner.

## Persona Red Flags

**The Bar Owner:** Most consequential action (merge) is the least communicated. Waits 20s with a frozen panel, no signal. Doesn't know it worked until the status badge updates.
