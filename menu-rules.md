# House Design Rules

This file is optional — the app extracts rules from an uploaded reference image.
But you can keep your evolving "house style" here as a second brain, paste it into
the brief box, or feed it to Claude Code when iterating on the template.

## Voice
- Cocktail names are literary, oblique, a little ominous.
- Descriptions are evocative, never explanatory. Max ~14 words.
- No exclamation marks. No "delicious". Let the ingredients imply the drink.

## Typography
- Serif display for names (Cormorant / Playfair / EB Garamond).
- Narrow sans, ALL CAPS, wide tracking for ingredient lists.
- Strong weight contrast between the two.

## Layout
- Sections flow lightest & brightest → most spiritous & brooding.
- Prices top-right of each item, italic, in the accent color.
- Generous vertical rhythm; one hairline frame inset from the page edge.
- No more than 7 cocktails. Curation over abundance.

## Ingredients
- Spirit first, always. Then modifiers, then bitters/garnish cues.
- Brand-specific where it matters; generic where it doesn't.

## Color
- Near-black grounds. Bone text. One metallic accent (brass/gold) + optional blood-red.
- Avoid pure #000 and pure #fff — use warm off-blacks and warm bones.
